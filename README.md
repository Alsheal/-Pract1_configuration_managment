# Эмулятор командной оболочки ОС

Учебный проект по разработке эмулятора командной оболочки UNIX-подобной операционной системы.

> **Текущий этап: Этап 3 — Виртуальная файловая система (VFS)**

---

# Описание

Данный проект представляет собой графический эмулятор командной оболочки с виртуальной файловой системой.

На первом этапе реализован интерактивный прототип, который позволяет пользователю вводить команды через графический интерфейс, разбирать их аргументы и получать результат выполнения.

На втором этапе функциональность расширена за счёт параметров запуска, загрузки стартового скрипта и диагностического вывода конфигурации.

На третьем этапе реализована виртуальная файловая система (VFS), которая загружает структуру каталогов и содержимое файлов из указанного каталога на диске в память. Команды `ls`, `cd` и `pwd` выполняют операции над виртуальной файловой системой, а команда `vfs-save` позволяет сохранить её состояние в отдельный каталог на диске.

Эмулятор поддерживает обработку аргументов в кавычках, проверку допустимости путей, обработку ошибок и выполнение команд из стартового скрипта.

Виртуальная файловая система работает с загруженным в память состоянием. Изменения в сохранённой копии выполняются отдельно от исходного каталога VFS.

Содержит класс `VirtualFileSystem`, реализующий виртуальную файловую систему.

- загрузку структуры каталогов и файлов из исходного каталога;
- хранение виртуальных каталогов в памяти;
- хранение содержимого файлов в виде байтов;
- определение текущего виртуального каталога;
- разрешение виртуальных путей;
- переход между каталогами;
- просмотр содержимого каталога;

- защиту от сохранения копии внутрь исходной VFS.

Исходный каталог используется для первоначальной загрузки данных. После загрузки операции чтения выполняются над структурами, хранящимися в памяти.

# Запуск

## Требования

Для запуска необходимы:

- Python версии 3.x;
- поддержка Tkinter;
- операционная система Windows, Linux или macOS.

Проверить установленную версию Python:

```bash
python --version
```

В Windows также можно использовать:

```powershell
py --version
```

В Linux/macOS обычно используется:

```bash
python3 --version
```

## Запуск приложения

Откройте терминал в корневой папке проекта:

```bash
cd shell-emulator
```

Запуск без дополнительных параметров:

```bash
python main.py
```

В Windows также можно использовать:

```powershell
py main.py
```

После запуска откроется графическое окно эмулятора.

## Запуск с параметрами

Для указания каталога VFS и стартового скрипта используются параметры командной строки:

```bash
python main.py --vfs "vfs" --script "scripts/startup.txt"
```

В Windows:

```powershell
py main.py --vfs "vfs" --script "scripts\startup.txt"
```

Если в проекте используется каталог `scripts/`, путь к стартовому скрипту необходимо изменить соответствующим образом.

Параметр `--vfs` задаёт каталог, из которого загружается виртуальная файловая система. Параметр `--script` задаёт файл с командами для автоматического выполнения при запуске.

# Виртуальная файловая система

## Принцип работы

Виртуальная файловая система загружает структуру каталогов и содержимое файлов из указанного каталога на диске.

При инициализации `VirtualFileSystem`:

1. Проверяется существование каталога-источника.
2. Проверяется, что указанный путь является каталогом.
3. Рекурсивно загружается структура каталогов.
4. Содержимое файлов считывается в память.
5. Устанавливается начальный виртуальный каталог `/`.

Для хранения данных используются две структуры:

- `directories` — множество виртуальных путей к каталогам;
- `files` — словарь, содержащий виртуальные пути к файлам и их содержимое в байтах.

Текущий каталог хранится в `current_path`.

Например, исходная структура:

```text
vfs/
├── documents/
│   └── notes.txt
└── папка с пробелами/
    └── пример.txt
```

Виртуальная структура имеет следующий вид:

```text
/
├── documents/
│   └── notes.txt
└── папка с пробелами/
    └── пример.txt
```

Корневой виртуальный каталог обозначается символом `/`.

## Обработка виртуальных путей

Команды работают с виртуальными путями, а не напрямую с текущим каталогом операционной системы.

Примеры:

| Путь | Назначение |
|---|---|
| `/` | Корневой каталог VFS |
| `/documents` | Каталог `documents` в корне |
| `notes.txt` | Относительный путь от текущего каталога |
| `..` | Переход в родительский каталог |
| `.` | Текущий каталог |

Попытка перейти выше корневого каталога запрещается.

Например:

```text
$ cd ../../
Ошибка: Доступ за пределами VFS запрещён
```

В случае ошибки текущий каталог остаётся без изменений.

# Поддерживаемые команды

## `ls`

Команда `ls` отображает содержимое текущего виртуального каталога.

### Без аргументов

```text
$ ls
documents
папка с пробелами
```

Вывод зависит от содержимого каталога VFS.

Если каталог пуст, выводится сообщение:

```text
Каталог пуст
```

### Подробный список: `ls -l`

Параметр `-l` включает подробный режим отображения.

```text
$ ls -l
d        0  documents
d        0  папка с пробелами
```

Для каталогов используется обозначение `d`, для файлов — `-`. Для файлов также отображается размер содержимого в байтах.

Другие аргументы команда не принимает.

Пример некорректного вызова:

```text
$ ls -a
Ошибка: использование ls [-l]
```

## `cd`

Команда `cd` изменяет текущий виртуальный каталог.

### Переход в каталог

```text
$ cd documents
Текущий каталог: /documents
```

### Возврат в родительский каталог

```text
$ cd ..
Текущий каталог: /
```

### Переход в корень

```text
$ cd /
Текущий каталог: /
```

### Каталог с пробелами

```text
$ cd "папка с пробелами"
Текущий каталог: /папка с пробелами
```

Если каталог не существует, выводится сообщение об ошибке.

Если указанный путь соответствует файлу, а не каталогу, выводится соответствующая ошибка.

При вызове `cd` без аргументов текущий виртуальный каталог сбрасывается в `/`.

## `pwd`

Команда `pwd` отображает текущий виртуальный путь.

Пример:

```text
$ pwd
/
$ cd documents
Текущий каталог: /documents
$ pwd
/documents
```

Команда не принимает аргументы.

## `vfs-save`

Команда `vfs-save` сохраняет снимок виртуальной файловой системы из памяти в отдельный каталог на диске.

### Формат

```text
vfs-save <путь>
```

### Пример

```text
$ vfs-save saved_vfs
VFS успешно сохранена: .../saved_vfs
```

При сохранении:

1. Проверяется путь назначения.
2. Проверяется, что каталог назначения не существует.
3. Создаётся каталог для сохранения.
4. Восстанавливается структура виртуальных каталогов.
5. Записывается содержимое файлов, хранящихся в памяти.
6. При ошибке выполняется попытка удалить неполную копию.

Сохранение не должно перезаписывать исходный каталог VFS или создавать копию внутри него.

Если каталог назначения уже существует, выводится сообщение об ошибке. Для повторной проверки необходимо указать новое имя каталога.

Например:

```text
$ vfs-save saved_vfs_test
```

Содержимое сохранённого каталога должно соответствовать состоянию виртуальной файловой системы на момент сохранения.

## `exit`

Команда `exit` завершает работу эмулятора.

Пример:

```text
$ exit
Эмулятор завершён
```

После выполнения команды графическое окно закрывается.

Команда не принимает аргументы.

# Обработка аргументов в кавычках

Для разбора команд используется стандартный модуль Python `shlex`.

Кавычки позволяют передавать имена каталогов, содержащие пробелы.

Например:

```text
$ cd "папка с пробелами"
Текущий каталог: /папка с пробелами
```

Команда:

```text
ls "hello world"
```

разбирается на имя команды и дважды не разделённый аргумент `hello world`, если он заключён в кавычки. При этом сама команда `ls` в текущей реализации не принимает произвольные аргументы, поэтому такой вызов будет отклонён обработчиком команды.

При вводе незакрытых кавычек парсер возвращает ошибку разбора.

---

# Обработка ошибок

Эмулятор обрабатывает ошибки разбора команд, неизвестные команды и ошибки операций с виртуальной файловой системой.

## Неизвестная команда

```text
$ unknown_command
Ошибка: неизвестная команда 'unknown_command'
```

После ошибки эмулятор продолжает работать.

## Попытка выйти за пределы VFS

```text
$ cd ../../
Ошибка: Доступ за пределами VFS запрещён
```

Корневой каталог виртуальной файловой системы является границей доступной области.

## Несуществующий каталог

```text
$ cd missing
Ошибка: Каталог не найден: missing
```

Текущий каталог не изменяется.

## Неправильные аргументы

Например:

```text
$ pwd extra
Ошибка: pwd не принимает аргументы
```

Для команд `ls`, `cd`, `pwd`, `vfs-save` и `exit` проверяется допустимое количество аргументов.

## Ошибки сохранения

При попытке сохранить VFS в существующий каталог или по недопустимому пути выводится сообщение об ошибке.

Пример:

```text
$ vfs-save saved_vfs
Ошибка сохранения VFS: Каталог назначения уже существует: ...
```

Ошибка отдельной команды не должна завершать работу приложения.

# Стартовый скрипт

Стартовый скрипт — текстовый файл, содержащий команды эмулятора, записанные по одной на строку.

Пример содержимого `script/startup.txt`:

```text
# Проверка виртуальной файловой системы
pwd
ls
ls -l
cd documents
pwd
ls
cd ..
cd "папка с пробелами"
ls
cd /
unknown_command
pwd
```

Пустые строки и строки, начинающиеся с `#`, пропускаются.

При запуске с параметром `--script` приложение последовательно выполняет команды из указанного файла и отображает результаты в графическом интерфейсе.

Ошибки отдельных команд отображаются пользователю, но не прекращают выполнение последующих команд. Выполнение останавливается при команде `exit`.

# Скрипты запуска операционной системы

Для упрощения запуска подготовлены скрипты для Windows и Linux/macOS.

## Windows — `script/run_windows.bat`

Скрипт запускает эмулятор из корневого каталога проекта с параметрами VFS и стартового скрипта.

Запуск из CMD:

```cmd
script\run_windows.bat
```

## Linux/macOS — `script/run_unix.sh`

Перед первым запуском при необходимости предоставьте права на исполнение:

```bash
chmod +x script/run_unix.sh
```

Запуск:

```bash
./script/run_unix.sh
```

Скрипты запуска должны передавать программе корректные пути к каталогу VFS и стартовому сценарию.

# Демонстрация работы этапа 3

Для проверки функциональности рекомендуется выполнить следующие действия.

## 1. Проверка текущего каталога

```text
$ pwd
/
```

Ожидаемый результат: отображается корневой виртуальный каталог.

## 2. Проверка списка каталогов

```text
$ ls
documents
папка с пробелами
```

Ожидаемый результат: отображаются каталоги, загруженные из исходной VFS.

## 3. Проверка подробного списка

```text
$ ls -l
d        0  documents
d        0  папка с пробелами
```

Ожидаемый результат: отображаются типы объектов и размеры файлов.

## 4. Проверка перехода в каталог

```text
$ cd documents
Текущий каталог: /documents
$ pwd
/documents
```

Ожидаемый результат: текущий виртуальный путь изменяется.

## 5. Проверка каталога с пробелами

```text
$ cd /
Текущий каталог: /
$ cd "папка с пробелами"
Текущий каталог: /папка с пробелами
$ ls
пример.txt
```

Ожидаемый результат: каталог открывается корректно, а его содержимое отображается.

## 6. Проверка выхода за пределы VFS

```text
$ cd /
Текущий каталог: /
$ cd ../../
Ошибка: Доступ за пределами VFS запрещён
$ pwd
/
```

Ожидаемый результат: попытка выйти за пределы VFS отклоняется, текущий путь остаётся `/`.

## 7. Проверка неизвестной команды

```text
$ unknown_command
Ошибка: неизвестная команда 'unknown_command'
```

Ожидаемый результат: выводится ошибка, эмулятор продолжает работу.

## 8. Проверка сохранения VFS

```text
$ vfs-save saved_vfs
```

Ожидаемый результат: создаётся новый каталог `saved_vfs`, содержащий копию виртуальной структуры и файлов.

Необходимо проверить наличие файлов:

```text
saved_vfs/
├── documents/
│   └── notes.txt
└── папка с пробелами/
    └── пример.txt
```

## 9. Проверка повторного сохранения

Повторно выполните:

```text
$ vfs-save saved_vfs
```

Ожидаемый результат: программа сообщает, что каталог назначения уже существует. Исходная VFS и ранее сохранённая копия не должны быть повреждены.

## 10. Проверка команды `exit`

```text
$ exit
```

Ожидаемый результат: графическое окно эмулятора закрывается.

# Дальнейшее развитие проекта

Проект разрабатывается в три этапа:

```text
Этап 1
REPL
   |
   v
Этап 2
Конфигурация
   |
   v
Этап 3
Virtual File System (VFS)
```

На третьем этапе реализованы загрузка виртуальной файловой системы в память, навигация по каталогам, просмотр содержимого и сохранение состояния VFS.

В дальнейшем проект может быть расширен за счёт:

- добавления команд создания и удаления файлов и каталогов;
- реализации копирования и перемещения файлов;
- расширения набора тестов;
- улучшения обработки ошибок;
- расширения возможностей стартовых скриптов.
