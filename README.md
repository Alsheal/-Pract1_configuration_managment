# Эмулятор командной оболочки ОС

Учебный проект по разработке эмулятора командной оболочки UNIX-подобной операционной системы.

> **Текущий этап: Этап 2 — REPL**

---

## Описание

Данный проект представляет собой графический эмулятор командной оболочки.

На первом этапе реализован минимальный интерактивный прототип, который позволяет пользователю вводить команды через графический интерфейс, разбирать их аргументы и получать результат выполнения.

Эмулятор имитирует работу UNIX-подобной командной строки, однако на данном этапе команды `ls` и `cd` являются заглушками.

В следующих этапах функциональность проекта будет расширяться.

---

## Цели этапа 1

В рамках первого этапа необходимо было:

* создать приложение с графическим интерфейсом;
* реализовать интерактивный режим работы;
* формировать заголовок окна на основе данных операционной системы;
* реализовать парсер команд;
* обеспечить корректную обработку аргументов в кавычках;
* реализовать команды `ls` и `cd` в виде заглушек;
* реализовать команду `exit`;
* добавить обработку ошибок;
* продемонстрировать работу прототипа в интерактивном режиме.

## Структура проекта

```text
shell-emulator/
│
├── main.py          # Графический интерфейс и точка входа
├── emulator.py      # Основная логика эмулятора
├── parser.py        # Парсер команд
├── commands.py      # Обработчики команд
├── README.md        # Документация проекта
└── .gitignore       # Исключения для Git
```

### `main.py`

Основной файл приложения.

Отвечает за:

* создание окна;
* создание элементов GUI;
* получение имени пользователя;
* получение имени компьютера;
* обработку ввода пользователя;
* отображение команд и результатов.

### `emulator.py`

Содержит основную логику обработки команд.

Отвечает за:

* получение строки команды;
* передачу команды парсеру;
* обработку ошибок;
* выполнение команды.

### `parser.py`

Содержит парсер команд.

Для корректной обработки кавычек используется стандартный модуль Python `shlex`.

### `commands.py`

Содержит реализацию поддерживаемых команд:

* `ls`;
* `cd`;
* `exit`.

На первом этапе `ls` и `cd` являются заглушками.

# Интерфейс

После запуска отображается графическое окно с заголовком вида:

```text
Эмулятор - [username@hostname]
```

Например:

```text
Эмулятор - [student@DESKTOP-ABC123]
```

`username` и `hostname` автоматически получаютcя из операционной системы.

В нижней части окна находится поле для ввода команд.

Принцип работы:

```text
┌──────────────────────────────────────────────────────┐
│ Эмулятор - [username@hostname]                      │
├──────────────────────────────────────────────────────┤
│                                                      │
│ Эмулятор запущен: username@hostname                 │
│ Введите команду. Доступные команды: ls, cd, exit.   │
│                                                      │
│ $ ls                                                 │
│ Команда: ls                                          │
│ Аргументы: []                                        │
│                                                      │
│ $                                                    │
├──────────────────────────────────────────────────────┤
│ [Введите команду____________________] [Enter]        │
└──────────────────────────────────────────────────────┘
```

# Поддерживаемые команды

## `ls`

На первом этапе команда `ls` реализована как заглушка.

При вводе команды выводится её имя и переданные аргументы.

### Без аргументов

```text
$ ls
Команда: ls
Аргументы: []
```

### С аргументом

```text
$ ls test
Команда: ls
Аргументы: ['test']
```

### С несколькими аргументами

```text
$ ls test folder
Команда: ls
Аргументы: ['test', 'folder']
```

> На первом этапе команда не выполняет реальный просмотр файловой системы. Работа с виртуальной файловой системой будет добавлена на следующих этапах.

---

## `cd`

Команда `cd` также является заглушкой.

### Пример

```text
$ cd test
Команда: cd
Аргументы: ['test']
```

### Несколько аргументов

```text
$ cd test folder
Команда: cd
Аргументы: ['test', 'folder']
```

> На первом этапе команда не изменяет текущий каталог. Реальная работа с каталогами будет реализована при добавлении VFS.

---

## `exit`

Команда `exit` завершает работу приложения.

### Пример

```text
$ exit
```

После выполнения команды окно эмулятора закрывается.

# Обработка аргументов в кавычках

Парсер поддерживает аргументы, заключённые в кавычки.

Для этого используется стандартный модуль Python:

```python
shlex
```

Например, команда:

```text
cd "my folder"
```

разбирается как:

```text
Команда: cd
Аргументы: ['my folder']
```

Таким образом, `my folder` воспринимается как **один аргумент**, несмотря на наличие пробела.

### Пример с несколькими аргументами

Ввод:

```text
ls "hello world" test
```

Результат:

```text
Команда: ls
Аргументы: ['hello world', 'test']
```

---

# Обработка ошибок

Эмулятор обрабатывает неизвестные команды.

Например:

```text
$ hello
Ошибка: неизвестная команда 'hello'
```

Неизвестная команда не приводит к завершению приложения — пользователь может продолжить работу.

Также обрабатываются ошибки синтаксического разбора команд.

Например, при вводе незакрытой кавычки:

```text
$ cd "test
```

будет выведено сообщение об ошибке парсинга.

После обработки ошибки эмулятор продолжает работать.
